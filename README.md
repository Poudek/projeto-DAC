## 📌 Sobre o Projeto

O **Projeto DAC** foi desenvolvido para centralizar a rotina acadêmica, facilitando o gerenciamento de dados de forma simples e intuitiva. A plataforma conta com controle de autenticação, dashboard interativo e módulos dedicados para gestão de aulas e persistência de dados.

### Principais Funcionalidades

- 🔐 **Autenticação & Controle de Sessão:** Fluxo de login e logout seguro entre visualizações.
- 📊 **Dashboard Administrativo:** Painel centralizado para navegação rápida entre recursos do sistema.
- 📅 **Gestão de Aulas & Horários:** Módulo completo para acompanhamento, cadastro e organização de cronogramas.
- 💾 **Persistência de Dados:** Estruturação para manipulação dinâmica de informações no cliente e integração com serviços backend.
- 📱 **Design Responsivo:** Interface construída com foco na usabilidade tanto em desktop quanto em dispositivos móveis.
